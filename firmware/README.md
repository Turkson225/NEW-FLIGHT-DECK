# FLIGHT DECK firmware\n\n## NodeMCU cloud telemetry\n\nThe NodeMCU sketch reads the MPU6050, aircraft battery divider, and Receiver Nano UART status. It then sends a validated read-only telemetry frame to the existing Supabase project's telemetry-ingest Edge Function.\n\nBefore uploading:\n\n1. Open firmware/FlightDeck_Node/FlightDeck_Node.ino.\n2. Set WIFI_SSID and WIFI_PASSWORD.\n3. Keep the existing Supabase URL in SUPABASE_TELEMETRY_URL.\n4. Replace DEVICE_SHARED_TOKEN with the same token stored as DEVICE_SHARED_TOKEN in the existing Supabase Edge Function secrets.\n5. Upload the sketch to the NodeMCU.\n6. Open Serial Monitor at 38400 baud and note the local IP.\n7. Open the local NodeMCU page and confirm CLOUD UPLINK shows SYNCED.\n8. Sign in to the FLIGHT DECK web dashboard, choose LIVE, and confirm telemetry appears.\n\nThe token must be at least 32 characters and must not be committed to GitHub. After bench validation, replace the temporary insecure TLS setting with CA certificate validation before field deployment.\n\n## Wiring\n\n- MPU6050 SDA → D2\n- MPU6050 SCL → D1\n- MPU6050 VCC → 3.3 V\n- MPU6050 GND → GND\n- Receiver Nano TX → level shifter → NodeMCU RX\n- NodeMCU TX → level shifter → Receiver Nano RX\n- Common ground between NodeMCU, level shifter, and Receiver Nano\n- Aircraft battery → measured voltage divider → NodeMCU A0\n- Never connect a battery directly to A0.\n\n## Cloud payload\n\nThe sketch sends LIVE frames containing:\n\n- pitch, roll, accelerometer, gyroscope, and MPU6050 temperature\n- aircraft and transmitter battery voltage when available\n- Receiver Nano link, failsafe, mixer, and channel status\n- Wi-Fi and cloud uplink state\n- firmware capabilities with hardware commands disabled\n\nThe browser remains read-only. Parachute deployment and actuator commands are not sent through Supabase.\n
